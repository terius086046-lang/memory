## Module B 피드백 기반 행동 변화 측정 지표 및 UI 반영 설계

CEO의 지시사항에 따라, Module B에서 수집되는 피드백(`feedback_record`)이 실제 사용자 행동 변화에 미친 영향을 측정하고 이를 UI에 시각적으로 반영하기 위한 디자인 명세 및 컨셉을 제시합니다.

### 1. 핵심 후속 지표(Metric) 정의

**지표명:** **Action Impact Score (AIS)**
*   **정의:** Module B 피드백 수신 이후, 사용자가 권위 강조 조치를 취한 후 실제로 목표 행동(예: 특정 페이지 방문, 구매 전환 등)을 성공적으로 완료한 비율.
*   **계산 공식 (가설):** $\text{AIS} = \frac{\text{Successful Action Completion}}{\text{Triggered Module B Interaction}}$
*   **목표:** AIS 값이 높을수록 권위 강조 트리거 로직과 Module B의 후속 조치 모듈이 사용자 행동 변화에 직접적인 긍정적 영향을 미쳤음을 의미합니다.

### 2. UI 반영 컨셉: '권위 피드백 대시보드' (Authority Feedback Dashboard)

AIS를 단순 수치로 제시하는 것을 넘어, 사용자가 자신의 노력이 어떻게 결과로 이어졌는지 직관적으로 이해하도록 네오-글래스모피즘 스타일을 적용합니다.

**디자인 컨셉:** **"투명한 권위의 흐름 (Transparent Authority Flow)"**
사용자가 Module B를 통해 얻은 피드백이 시스템 내에서 어떻게 가중치(Weight)를 얻고 다음 행동으로 연결되었는지를 시각적으로 표현합니다.

#### 2.1. 레이아웃 및 구성 요소 명세

| 영역 | 구성 요소 | 디자인 스타일/색상 적용 | 목적 |
| :--- | :--- | :--- | :--- |
| **상단 요약** | **AIS 대시보드 카드** | 배경: 투명한 딥 블루 (Deep Blue, #0A193B). 경계선: 밝은 청록색(Electric Cyan, #00FFFF)의 미세한 테두리. | 현재 세션에서 측정된 핵심 성과를 즉각적으로 인지. |
| **중앙 시각화** | **행동 변화 흐름 그래프 (Flow Graph)** | 네오-글래스모피즘 스타일의 투명한 레이어 위에, 성공적인 행동(Success)을 나타내는 빛나는 노드와 연결선(Flow Line)을 배치. | 피드백 $\rightarrow$ 조치 $\rightarrow$ 결과의 인과 관계를 시각화. |
| **세부 피드백** | **피드백 상세 로그 (Feedback Log)** | 미니멀한 글래스모피즘 박스. 각 레코드는 투명도를 조절하여 중요도에 따라 레이어링. | 사용자가 특정 피드백이 어떤 행동 변화를 유발했는지 직접 확인. |

#### 2.2. 디자인 상세 사양 (Figma/CSS 명세)

1.  **색상 팔레트:**
    *   **Primary Background:** `#0A193B` (Deep Blue - 권위의 기반)
    *   **Accent Color (Success):** `#00FFFF` (Electric Cyan - 긍정적 변화/성과 강조)
    *   **Secondary Element:** `rgba(255, 255, 255, 0.1)` (투명도 적용)

2.  **AIS 시각화:**
    *   현재 AIS 값을 **원형 진행도 바(Progress Bar)**와 **불투명한 게이지(Gauge)** 형태로 동시에 표시합니다.
    *   **게이지 채움:** 성공률에 따라 `#00FFFF`의 투명도를 동적으로 변화시켜, 목표 달성 시 가장 밝고 불투명하게 빛나도록 설계합니다.

3.  **흐름 시각화 (Flow Graph):**
    *   사용자 행동 흐름은 **좌측에서 우측으로** 진행하며, 각 단계(Trigger $\rightarrow$ Action $\rightarrow$ Result)는 투명한 블록 형태로 표현됩니다.
    *   성공적인 변화가 발생한 경로는 `#00FFFF` 색상의 선으로 강조하여 시각적 경로를 명확히 합니다.
