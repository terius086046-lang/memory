💻 Developer: 작업 시작합니다.

요청하신 '간단한 벽돌게임'을 구현하기 전에, 개발 방향과 구체적인 요구사항을 명확히 확인해야 합니다. 어떤 종류의 게임을 원하시는지에 따라 기술 스택과 구현 방식이 완전히 달라집니다.

다음 질문들에 대한 답변을 제공해 주시면, 가장 효율적이고 실행 가능한 결과물을 도출할 수 있습니다.

### 🧱 게임 요구사항 확인 질문

1.  **게임 목표 (Game Goal):** 플레이어가 궁극적으로 달성해야 하는 목표는 무엇입니까? (예: 특정 점수 달성, 최대한 많은 벽돌 제거, 시간 제한 내에 레벨 클리어 등)
2.  **승리 조건 (Win Condition):** 게임이 종료되고 승리하는 조건은 무엇입니까? (예: 모든 벽돌을 제거했을 때, 일정 시간 경과 시 등)
3.  **게임 방식 (Gameplay Style):** 게임의 흐름은 어떤 형태를 원하십니까?
    *   2D 화면 기반 (그래픽 필요)
    *   텍스트 기반 (ASCII 아트 또는 콘솔 환경)
    *   턴제 또는 실시간 상호작용
4.  **기술 스택 선호도 (Tech Stack Preference):** 어떤 언어와 엔진을 사용하여 구현하고 싶으십니까? (예: Python + Pygame, JavaScript + Canvas, C++ 등)

이 정보가 준비되면, 제가 가장 적합한 기술 스택과 구체적인 규칙을 정의하여 바로 코드를 작성하겠습니다.
