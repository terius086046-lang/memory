# 아키텍트 대시보드 최종 UI/UX 컴포넌트 상세 디자인 명세

본 문서는 Business가 확정한 '$149$ 가격 전략'과 '권위 기반 통제(Authority-Based Control)' 철학을 시각적으로 구현하는 '아키텍트 대시보드'의 최종 UI/UX 컴포넌트 상세 디자인 명세를 제공합니다. 네오-글래스모피즘 스타일(투명함과 권위)을 핵심 디자인 언어로 채택하여, 사용자가 통제감과 전문성을 즉각적으로 인식하도록 설계되었습니다.

## 1. 디자인 철학 및 목표 (Design Philosophy & Goal)

*   **핵심 원칙:** 권위 기반 통제 (Authority-Based Control). 사용자는 데이터의 흐름을 명확히 인지하고, 시스템이 제공하는 구조적 우위를 통해 심리적 통제감을 경험해야 한다.
*   **스타일:** 네오-글래스모피즘 (Neo-Glassomorphism). 깊이감 있는 투명도(Frosted Glass)와 미니멀한 구조를 결합하여 데이터의 중요성을 강조한다.
*   **색상 팔레트:**
    *   **배경 (Background):** Dark Mode 기반의 짙은 차콜 그레이 또는 블랙 (`#1A1A2E` 계열).
    *   **주요 레이어 (Glassmorphism Effect):** 반투명 화이트/라이트 그레이 (`rgba(255, 255, 255, 0.15)`).
    *   **액센트 색상 (Authority Accent):** 골드 계열 (`#FFD700` 또는 `#FFC300`)을 핵심 KPI, 경계선, 활성화된 상태에 사용하여 권위를 부여한다.

## 2. 컴포넌트 구조 상세 (Component Structure Detail)

### A. 대시보드 레이아웃 (Dashboard Layout)

*   **전체 구성:** 좌측 내비게이션(Navigation) + 중앙 메인 데이터 영역 + 우측 통제 패널(Control Panel).
*   **네비게이션 (좌측):** 고정형 다크 모드 네비게이션. 아이콘과 텍스트는 최소화하되, 현재 활성화된 항목은 골드 액센트로 강조한다.
*   **데이터 카드 (Data Cards):** 모든 KPI와 지표는 독립적인 'Glass Card' 형태로 분리하여 배치한다. 각 카드는 미묘한 그림자(Soft Shadow)를 적용하여 깊이감을 부여하고, 투명도를 통해 배경의 차콜 그레이가 비치게 한다.

### B. 핵심 KPI 카드 상세 디자인 (Core KPI Card Detail)

모든 KPI 카드는 다음 구조를 따른다.

| 요소 | 스타일/설명 | 권위 반영 방식 |
| :--- | :--- | :--- |
| **카드 배경** | 반투명 화이트 (`rgba(255, 255, 255, 0.15)`) | 투명도를 통해 시스템의 '내부 구조'가 시각적으로 노출됨을 암시. |
| **KPI 제목** | 크고 굵은 산세리프체 (예: Inter Bold). 골드 색상 (`#FFC300`). | 가장 중요한 정보에 권위(Authority)를 부여. |
| **수치 값** | 중앙 정렬, 매우 큰 폰트 크기. 흰색 또는 밝은 그레이. | 데이터의 절대적 중요성을 강조. |
| **추이 표시** | 이전 기간 대비 변화율을 작은 화살표와 함께 표시. (상승: 녹색 계열 / 하락: 주황/빨강 계열). | 통제 가능한 흐름(Control)을 시각화. |
| **데이터 소스/컨텍스트** | 카드 하단에 작게 데이터의 출처나 정의를 명시 (`Source: event_log_table`). | 모든 데이터는 시스템 구조 내에서 생성되었음을 강조하여 신뢰도를 높임. |

### C. 권위 기반 통제 요소 (Authority-Based Control Elements)

1.  **필터/그룹 제어:** 모든 데이터 뷰 상단에 'Filter by Authority' 드롭다운을 배치하여, 사용자가 어떤 그룹(A/B 테스트 그룹 등)의 데이터를 볼지 선택하도록 강제한다.
2.  **데이터 계층화:** 핵심 지표(MAU, 전환율)는 가장 앞에, 세부 이벤트 로그는 하위에 위치시켜 정보의 위계질서를 확립한다.
3.  **상태 표시:** 시스템이 제공하는 분석 결과에 대해 '확정된 통제 상태'를 시각적 뱃지나 색상 변화로 명확히 표시하여 사용자의 의사결정을 유도한다.

## 3. 데이터 흐름 및 와이어프레임 연계 (Data Flow & Wireframe Linkage)

*   **데이터 입력:** 이벤트 로그 테이블(`event_log_table`)의 필드(`ab_test_group`)가 대시보드 시각화의 핵심 기준으로 사용됨을 명시한다.
*   **와이어프레임 반영 지침:** 모든 데이터 카드는 해당 KPI가 어떤 이벤트 로그 그룹에서 파생되었는지에 대한 **메타데이터 링크**를 포함해야 한다.
