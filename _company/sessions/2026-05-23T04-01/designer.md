## 시스템 안정성($ARL$) 강조 썸네일 및 CTA 디자인 명세 최종안

Business와 Developer의 요구사항에 따라, 시스템 안정성($ARL$) 수치를 시각적으로 가장 강력하게 강조하는 썸네일(Thumbnail) 및 Call-to-Action(CTA) 컴포넌트의 최종 디자인 명세를 Primary Blue와 Accent Teal 색상을 기반으로 확정합니다. 네오-글래스모피즘 스타일을 유지하며 권위감과 데이터 중심의 느낌을 극대화합니다.

### 1. 핵심 컬러 팔레트 정의

| 용도 | 색상 이름 | HEX 코드 | 역할 및 설명 |
| :--- | :--- | :--- | :--- |
| **Primary (주요 강조)** | Primary Blue | `#3457D5` | 시스템 안정성($ARL$)의 핵심 지표, 권위와 신뢰를 상징. 배경 및 주요 프레임에 사용. |
| **Accent (보조 강조)** | Accent Teal | `#1E8C9A` | 보조 정보, 성공 상태(Stability Achieved), 데이터 흐름을 나타냄. |
| **Background** | Light Surface | `#F4F7FA` | 네오-글래스모피즘의 투명한 배경으로 사용. |
| **Text/Data** | Dark Slate | `#2C3E50` | 주요 텍스트 및 $ARL$ 수치에 사용되어 명확성을 확보. |

### 2. 썸네일 컴포넌트 디자인 명세 (Thumbnail Component)

**목표:** 시스템 안정성($ARL$)을 즉각적으로 인지시키고 클릭을 유도한다.

**레이아웃 컨셉:** 중앙 집중형 게이지(Gauge) 및 배지(Badge) 강조.

| 요소 | 세부 사양 | 디자인 적용 (네오-글래스모피즘 기반) |
| :--- | :--- | :--- |
| **배경** | 전체 영역 | Light Surface (`#F4F7FA`)의 투명한 블러 효과를 적용하여 시스템 안정성 데이터를 돋보이게 함. |
| **$ARL$ 게이지** | 핵심 시각 요소 | 중앙에 Primary Blue(`#3457D5`)로 채워진 원형 또는 사각형의 진행률 표시줄(Progress Bar)을 배치. **$ARL$ 수치**는 굵은 Dark Slate(`#2C3E50`)로 크게 표시. |
| **안정성 배지** | 상태 표시 | $ARL$ 수치가 목표치 이상일 경우, Accent Teal(`#1E8C9A`) 배경에 흰색 텍스트로 "Stable" 또는 "High Stability" 배지를 중앙 하단에 배치. |
| **제목 영역** | 콘텐츠 제목 | 상단 중앙에 Dark Slate 색상의 깔끔한 타이포그래피를 사용하여 콘텐츠 주제를 명시. |

**예시 레이아웃 좌표 (가정):**
*   썸네일 전체 크기: 16:9 비율 권장.
*   $ARL$ 게이지 위치: 화면 중앙(X: 50%, Y: 45%).
*   핵심 $ARL$ 수치 (`N`): 폰트 크기 80px 이상, 색상 Primary Blue(`#3457D5`).

### 3. CTA 컴포넌트 디자인 명세 (Call-to-Action Component)

**목표:** 사용자가 안정성 확인 후 다음 행동(데이터 접근 또는 구매)을 자연스럽게 취하도록 유도한다.

**레이아웃 컨셉:** 대비를 통한 행동 유도.

| 요소 | 세부 사양 | 디자인 적용 (네오-글래스모피즘 기반) |
| :--- | :--- | :--- |
| **Primary CTA 버튼** | 핵심 액션 버튼 | 배경: Primary Blue(`#3457D5`). 텍스트: 흰색. 그림자 효과는 최소화하여 플랫한 네오-글래스모피즘 느낌 유지. (예: `border-radius: 12px; box-shadow: 0 4px 6px rgba(52, 87, 213, 0.3);`) |
| **Secondary CTA 버튼** | 보조 액션 버튼 | 배경: Accent Teal(`#1E8C9A`). 텍스트: 흰색. $ARL$ 수치가 낮거나 추가 정보를 요구할 때 사용 (예: "View Data", "Upgrade Plan"). |
| **정보 제공 영역** | $ARL$ 설명 | CTA 버튼 바로 위에 작은 텍스트로 "$ARL$ 기준에 대한 간략한 설명"을 Accent Teal 색상으로 표시하여 신뢰도를 높임. |

### 4. 디자인 가이드 요약 (Designer's Guidelines Summary)

1.  **일관성 유지:** 모든 컴포넌트는 Primary Blue와 Accent Teal의 조합만을 사용하여 시스템 안정성($ARL$)과 관련된 정보임을 명확히 해야 한다.
2.  **데이터 우선:** $ARL$ 수치는 디자인 내에서 가장 큰 시각적 요소로 취급되어야 하며, 사용자가 스캔하는 즉시 상태를 파악할 수 있어야 한다.
3.  **네오-글래스모피즘 적용:** 모든 경계선과 깊이감은 미묘한 그림자와 투명도(Glassmorphism) 효과를 통해 표현하여 기술적 권위와 세련됨을 동시에 전달한다.
