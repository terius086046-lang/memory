## 아키텍트 대시보드 최종 디자인 명세 및 와이어프레임 통합

본 산출물은 Developer의 데이터 구조(`event_log_table`)와 Business가 확정한 핵심 KPI(MAU, 전환율 추적 흐름)를 기반으로, 네오-글래스모피즘 스타일을 적용하여 '아키텍트 대시보드'의 시각적 완성도를 극대화하는 최종 디자인 명세 및 와이어프레임을 통합하여 제시합니다.

### 1. 디자인 시스템 요약 (Neumorphism 기반)

| 항목 | 상세 내용 | 코드/값 | 비고 |
| :--- | :--- | :--- | :--- |
| **핵심 스타일** | 네오-글래스모피즘 (Neumorphism) | - | 투명도와 깊이감 강조 |
| **배경 색상** | 소프트 그레이 (Light Gray Background) | `#E0E5EC` | 전체적인 차분함 유지 |
| **카드/패널 색상** | 밝은 회색 (Raised/Inset Effect) | `#FFFFFF` / `#F3F4F6` | 입체감 부여 |
| **주요 강조색 (Primary)** | 네오-블루 (Authority Blue) | `#4A90E2` | 핵심 KPI 및 액션 버튼 |
| **보조 색상 (Success/Warning)** | 소프트 그린 / 오렌지 | `#7ED321` / `#F5A623` | 상태 표시용 |
| **타이포그래피** | 산세리프 계열 (권위 강조) | Pretendard / Inter | 가독성 최우선 |

### 2. 와이어프레임 및 레이아웃 상세 (Desktop View)

**목표:** 권위와 구조를 시각적으로 명확하게 전달하여 사용자가 데이터의 흐름을 즉시 파악하도록 한다.

#### A. 대시보드 전체 레이아웃
*   **레이아웃:** 2단 컬럼 (Sidebar Navigation + Main Content Area)
*   **구조:** 좌측에 네비게이션, 우측에 KPI 위젯 및 데이터 시각화 영역 배치.

#### B. 주요 컴포넌트 상세 디자인 명세

| 영역 | 컴포넌트 | 디자인 스타일 | 데이터 매핑 (Developer 연계) | 좌표/크기 가이드 |
| :--- | :--- | :--- | :--- | :--- |
| **헤더** | 대시보드 제목 및 사용자 상태 | Inset Shadow (깊이감) | `user_id` 기반 개인화 정보 | Top: 60px, Full Width |
| **KPI 요약 섹션** | 핵심 지표 카드 (MAU, 전환율) | Raised Effect (부각), Primary Color Border | `user_sessions`, `event_log_table` 집계 값 | Left: 100%, Height: 25% (3분할) |
| **이벤트 흐름 시각화** | A/B 테스트 그룹별 전환율 플로우 차트 | 네오-글래스모피즘 바/라인 그래프 | `event_log_table.ab_test_group` 기반 집계 | Main Area: 60% Width, Height: 40% |
| **실시간 로그 테이블** | 이벤트 로그 상세 테이블 | Soft Inset (정보 전달), Light Border | `event_log_table` 전체 데이터셋 | Bottom: 100%, Full Width |

#### C. 핵심 시각화 요소 정의 (A/B 테스트 흐름)

1.  **그룹 비교 바:** A 그룹과 B 그룹의 전환율(Conversion Rate)을 막대 그래프로 비교하여, 권위 중심 가설이 어느 쪽에서 더 강력한지 직관적으로 보여준다.
    *   **스타일:** 두 개의 분리된 네오-블루/그레이 바를 사용하여 시각적 계층을 형성한다.
2.  **흐름 강조:** 이벤트 발생 시점(`event_timestamp`)과 그룹 할당(`ab_test_group`)이 명확하게 연결되는 흐름을 화살표나 연결선으로 표현하여 데이터의 인과관계를 강조한다.

### 3. 디자인 가이드 및 실행 지침

1.  **레이아웃 우선순위:** 모든 정보는 '권위(Authority)'를 시각적으로 전달하는 데 초점을 맞춘다. 가장 중요한 KPI와 테스트 그룹 비교가 화면 상단에 위치해야 한다.
2.  **네오-글래스모피즘 적용:** 모든 카드(`Card`), 입력 필드(`Input Field`), 테이블 행(`Table Row`)에는 미세한 그림자(Soft Shadow)를 사용하여 배경으로부터 '떠오르는' 듯한 입체감을 부여한다. 이는 데이터의 중요도를 시각적으로 높이는 역할을 한다.
3.  **데이터 명확성:** 모든 그래프와 수치는 최소 2자리 소수점까지 표시하며, 어떤 그룹이 통제력을 갖는지(`A` vs `B`)를 색상과 레이아웃으로 즉시 인식할 수 있도록 설계한다.
