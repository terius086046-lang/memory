# 🚀 최종 디자인 명세서 및 와이어프레임 (Developer 배포용)

본 문서는 최종 가격 모델($197)과 '권위 강조(Authority Emphasis)' 전략을 모든 핵심 전환 지점에 극대화하여 UI/UX를 확정하고 프로토타입 제작을 시작할 수 있도록 개발팀에 즉시 배포하기 위해 작성되었습니다.

## 1. 디자인 시스템 및 스타일 가이드 (Visual System & Style Guide)

### 1.1. 핵심 철학: 권위 강조 (Authority Emphasis)
모든 디자인 요소는 사용자가 **시스템의 통제권과 권위**를 인지하도록 설계되어야 합니다. 이는 투명성(Transparency)과 견고함(Authority)을 시각적으로 표현합니다.

*   **레이아웃 원칙:** 정보의 계층 구조를 명확히 하여, 가장 중요한 권한/데이터가 최상단에 배치됩니다.
*   **시각적 위계:** 권위 강조 요소는 강력한 대비와 무게감을 사용하여 주목도를 극대화합니다.

### 1.2. 컬러 팔레트 및 타이포그래피 (Color & Typography)

| 요소 | 역할 | 색상 코드 (Hex) | 적용 전략 |
| :--- | :--- | :--- | :--- |
| **Primary Authority Color** | 권위 강조/CTA 활성화 (Authority Action) | `#007BFF` (강한 블루 계열) | 핵심 전환 버튼, 권한 활성화 상태 표시. 신뢰와 행동 유도. |
| **Value Framing Accent** | 가치 및 결과 강조 (Value Emphasis) | `#28A745` (그린 계열) | 성공 지표(KPI), 긍정적인 결과 데이터. |
| **Background/Transparency** | 투명성 및 구조 강조 (Neo-Glassomorphism) | `rgba(255, 255, 255, 0.7)` | 전체 대시보드 배경, 카드 요소에 적용하여 깊이감 부여. |
| **Primary Typeface** | 권위 표현 (Authority Emphasis) | Inter / Montserrat (Bold/Semi-Bold 계열) | 제목, 핵심 지표(KPI), 시스템 메시지. 무게감을 강조. |
| **Secondary Typeface** | 정보 전달 (Value Framing) | Roboto / Noto Sans | 보조 텍스트, 상세 설명, 데이터 표. 가독성 극대화. |

### 1.3. 컴포넌트 디자인 명세: '시스템 권한 활성화' 모달 (Authority Modal Specification)

이 모달은 사용자가 시스템의 권한을 활성화하는 가장 중요한 전환 지점입니다.

*   **스타일:** 네오-글래스모피즘 기반, 투명하고 미니멀하며 구조적인 디자인 적용.
*   **레이아웃:** 중앙 정렬된 핵심 액션 버튼과 상단에 시스템 상태(권한 수준)를 명확히 표시하여 권위를 시각적으로 전달합니다.
*   **Authority Element:** '활성화' 버튼은 Primary Authority Color(`#007BFF`)로 채워지며, 마우스 오버 시 미세하게 밝아지는 애니메이션을 적용하여 클릭 유도를 극대화합니다.
*   **정보 배치:** 권한 활성화의 **결과(Value Framing)**를 모달 상단에 요약하여 제시하고, 상세 조건은 하단에 명확히 구분하여 배치합니다.

## 2. 와이어프레임 구조 (Wireframe Structure)

다음은 최종 '아키텍트 대시보드'의 핵심 와이어프레임 구조입니다. 이 구조는 개발팀이 즉시 프로토타입 제작을 시작할 수 있도록 명확한 정보 계층을 제공합니다.

### 2.1. 메인 대시보드 (Dashboard - Authority View)

*   **상단 헤더 (Authority Bar):**
    *   회사 로고 및 시스템 상태 표시 (최고 권위 표시).
    *   사용자 프로필 및 **'시스템 권한 관리' 바로가기 버튼**.
*   **핵심 KPI 섹션 (Value Framing Focus):**
    *   **KPI 1: MAU 추이:** 시간 경과에 따른 사용자 활동량 변화 (강한 시각적 강조).
    *   **KPI 2: Trial-to-Paid Conversion Rate (T2P CR):** 현재 전환율 및 목표(30%) 대비 진행률을 게이지 또는 대시보드 형태로 표시. (가장 큰 권위 강조 요소)
    *   **KPI 3: 활성 사용자 수:** 현재 시스템 내에서 권한을 가진 사용자 총 수.
*   **데이터 시각화 섹션 (Architect View):**
    *   **데이터 구조 개요:** `user_sessions`, `event_log_table`의 데이터 무결성을 나타내는 간략한 요약 카드. (개발팀에게 데이터 기반임을 명시)
    *   **권한 상태 대시보드:** 사용자가 현재 접근 가능한 시스템 모듈(예: Pricing, Analytics, Settings)을 트리 구조 또는 아코디언 형태로 시각화하여 권한 구조를 표현.

### 2.2. 사용자 여정 (User Flow - Data Acquisition & Conversion)

*   **단계 1: 데이터 업로드/연동:** 사용자가 자신의 데이터를 시스템에 연결하는 과정. (투명성 강조)
    *   UI 요소: 드래그 앤 드롭 영역, API 키 입력 필드.
*   **단계 2: 분석 및 권한 요청:** 데이터 연동 후, 시스템이 사용자에게 필요한 권한을 요청하는 단계.
    *   UI 요소: '데이터 검증 완료' 상태 표시 후, **'시스템 접근 권한 승인' 모달** 호출. (여기서 위에서 정의된 Authority Modal 적용)
*   **단계 3: 결과 확인 및 전환:** 권한 부여 후, 사용자가 최종 분석 결과(견적 등)를 확인하고 결제/구독을 진행하는 단계.
    *   UI 요소: 최종 견적 요약 카드에 $197 모델이 가장 눈에 띄게 표시되며, CTA 버튼은 Primary Authority Color로 강조됨.
