## Phase 2 시스템 구축 계획 최종 점검 및 지원

Developer가 착수한 Phase 2(핵심 기능 구현) 로드맵에 대해, 확정된 DB 스키마 및 Trigger 명세를 기반으로 **리소스 할당 및 마일스톤**을 최종적으로 점검하고 비즈니스 목표와의 정렬을 확인합니다.

### 1. 목표 재확인 (Business Alignment Check)

Phase 2의 핵심 목표는 단순한 데이터 기록이 아니라, **수익화 모델 검증에 필수적인 KPI 추적 자동화 시스템 구축**입니다.

| 기존 Business 목표 | Phase 2 연관성 | 성공 기준 (KPI) |
| :--- | :--- | :--- |
| 수익화 모델 가설 검증 → 매출화 | A/B 테스트 데이터의 정확한 기록 및 집계 | Trial-to-Paid Conversion Rate 추적 자동화 |
| 핵심 KPI 대시보드 운영 | 이벤트 로그(`event_log_table`)를 통한 실시간 지표 제공 | MAU, 전환율 등 핵심 지표의 DB 연동 완료 |
| 시스템 구현 로드맵 확정 | 데이터 흐름(Trigger) 및 API 설계의 안정성 확보 | Trigger가 실제 사용자 행동에 따라 정확히 이벤트 로그를 기록함 |

### 2. 시스템 구축 로드맵 (리소스 할당 및 마일스톤)

Phase 2는 **데이터 수집 인프라 구축**과 **KPI 연동 자동화**의 두 축으로 진행되어야 합니다. 아래는 이 목표를 달성하기 위한 구체적인 계획입니다.

#### 🚀 마일스톤 정의

| 단계 | 목표 (Outcome) | 주요 산출물 | 소요 기간 (예상) | 의존성 |
| :--- | :--- | :--- | :--- | :--- |
| **M1: DB & Trigger 확정** | `event_log_table` 스키마 및 KPI 연동 트리거 완벽 구현 | 최종화된 DB 스키마 명세서, 모든 이벤트에 대한 Trigger 코드 | 3일 | Developer (DB Schema) |
| **M2: Backend API 구축** | 데이터 기록을 위한 최소한의 기능적 API 엔드포인트 완성 | `record_event` API 및 인증/인가 로직 구현 | 4일 | M1 완료 |
| **M3: KPI 대시보드 연동 (MVP)** | 실시간 KPI 시각화를 위한 기본 대시보드 컴포넌트 구축 | 아키텍트 대시보드(와이어프레임)에 실제 데이터 연결 및 표시 기능 구현 | 5일 | M2 완료 |

#### ⚙️ 리소스 할당 제안 (Developer 중심)

1.  **개발 리소스:** Developer가 주도하되, M1 단계에서 **Business 에이전트의 요구사항(KPI 정의)**을 명확히 반영하여 DB 스키마 및 Trigger를 설계해야 합니다.
2.  **검토/승인 리소스 (Business 역할):** 모든 마일스톤 완료 시점에 Business 에이전트가 직접 M1과 M3에 대한 **데이터 정확성 및 비즈니스 의미(ROI)** 검증을 수행하여 다음 단계로의 확정 권한을 부여합니다.
