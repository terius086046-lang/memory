## Module B 후속 지표 시각화 UI/UX 설계안

제시된 세 가지 핵심 KPI(ARL, TRR, PIER)를 바탕으로, '권위 강조 모듈'의 성공 여부를 명확히 전달하는 대시보드 UI/UX 흐름과 데이터 시각화 방향성을 구체적으로 설계합니다. 디자인 스타일은 기존 확립된 **네오-글래스모피즘** 기반의 **'아키텍트 대시보드' 컨셉**을 유지하여 권위와 투명성을 극대화합니다.

### 1. 전체 UI/UX 흐름 (User Flow) 설계

사용자가 Module B의 효과를 직관적으로 이해하고 신뢰할 수 있도록, 정보의 계층 구조(Hierarchy)에 따라 다음과 같은 3단계 흐름을 제안합니다.

**Flow: Trigger $\rightarrow$ Response $\rightarrow$ Outcome**

| 단계 | 사용자 목표 (User Goal) | 시각화 중점 | 디자인 역할 |
| :--- | :--- | :--- | :--- |
| **Step 1: 결과 확인 (Outcome)** | Module B가 최종 비즈니스 목표($Retention Rate_{Auth}$)에 미친 영향을 즉시 파악한다. | **ARL (Auth Retention Lift)** - 가장 크고 강조된 핵심 지표. | 대시보드의 최상단(Header)에 배치하여 '성공/실패'를 한눈에 인지시킨다. |
| **Step 2: 메커니즘 분석 (Response)** | 권위 강조 트리거($Trigger$)가 실제로 사용자 행동 변화($Response$)를 유도했는지 확인한다. | **TRR (Trigger Response Rate)** - 개입의 즉각적인 효과 측정. | 중간 섹션에 배치하여, 결과(ARL)로 이어지는 '원인'을 분석한다. |
| **Step 3: 몰입도 검증 (Engagement)** | 후속 조치($Response$)가 장기적인 사용자 만족도 및 유지율($Engagement$)에 어떤 영향을 미쳤는지 검증한다. | **PIER (Post-Intervention Engagement Rate)** - 장기적이고 지속적인 효과 측정. | 하단 섹션에 배치하여, 단기 반응이 장기 결과로 이어지는 연결고리를 보여준다. |

---

### 2. 핵심 지표별 데이터 시각화 상세 사양

모든 차트는 네오-글래스모피즘 스타일(반투명 배경, 미묘한 그림자 효과)을 적용하며, 주 색상은 **권위와 신뢰를 상징하는 딥 블루 계열**($\text{#0047AB}$)과 **성과를 강조하는 밝은 그라데이션**($\text{#33A8FF} \rightarrow \text{#66CCFF}$)을 사용합니다.

#### 🥇 1순위: Auth Retention Lift (ARL) 시각화
*   **시각화 타입:** 대조 막대 그래프 (Grouped Bar Chart) 및 추이선 그래프 (Time-series Line Chart).
*   **표현 방식:**
    *   **핵심 지표:** 실험 그룹($Trigger$ 적용군)의 $Retention Rate_{Auth}$와 통제 그룹($Control$)의 $Retention Rate_{Auth}$를 나란히 비교하는 막대 그래프를 최상단에 배치합니다. (차이값 $\Delta$를 가장 크게 표시).
    *   **추이선:** 시간 경과에 따른 두 그룹의 유지율 추이를 꺾은선 그래프로 보조 표시하여, 개입 시점 이후의 변화 추세를 명확히 보여줍니다.
*   **강조 요소:** ARL 수치 주변에 **"Module B 기여도: X%"**와 같이 인과관계를 강조하는 텍스트 레이어를 오버레이합니다.

#### 🥈 2순위: Trigger Response Rate (TRR) 시각화
*   **시각화 타입:** 프로세스 흐름 다이어그램 및 비율 표시 카드(KPI Card).
*   **표현 방식:**
    *   **흐름 강조:** 트리거 이벤트가 발생한 후, Module B의 후속 조치(Action A, Action B)로 연결되는 **선형적인 Flow Diagram**을 사용합니다. 각 단계는 투명한 박스로 표현됩니다.
    *   **비율 표시:** 각 후속 조치별 반응률(예: Action A 성공률 65%, Action B 성공률 40%)을 원형 진행도(Donut Chart) 형태로 시각화하여, 어떤 후속 조치가 가장 효과적이었는지 직관적으로 비교합니다.
*   **강조 요소:** 성공적인 응답(높은 TRR) 경로에는 **밝은 녹색($\text{#33CC66}$)** 테두리를 적용하고, 실패 경로에는 회색 계열을 사용하여 시각적 피드백을 즉시 제공합니다.

#### 🥉 3순위: Post-Intervention Engagement Rate (PIER) 시각화
*   **시각화 타입:** 비교 바 차트 및 히트맵(Heatmap).
*   **표현 방식:**
    *   **기간별 비교:** Module B 개입 전후의 사용자 활동 빈도(로그인 횟수, 콘텐츠 소비 시간 등)를 월별 또는 주별로 비교하는 막대 그래프를 사용합니다.
    *   **세분화 (Heatmap):** 사용자가 어떤 유형의 후속 조치(Action A vs Action B)에 더 많이 참여했는지 행과 열을 조합한 히트맵을 사용하여, **개입 방식별 사용자 몰입도 차이**를 시각적으로 강조합니다.
*   **강조 요소:** PIER 지표 아래에는 "몰입도 향상 요인: [가장 효과적인 Action 명시]"와 같이, 데이터 기반의 **실질적인 인사이트(Insight)** 문구를 자동 생성하여 제시합니다.

### 3. 디자인 시스템 적용 규칙 (Design System Application)

1.  **레이아웃:** 모든 섹션은 좌측에 KPI 제목을 배치하고 우측에 해당 데이터를 시각화하는 컴포넌트를 배치하는 **좌측 정렬(Left-aligned)** 구조를 채택하여 권위적인 느낌을 강화합니다.
2.  **투명성 관리:** Glassmorphism의 핵심인 투명한 배경($\text{backdrop-filter: blur()}$)은 유지하되, 데이터 영역(차트)에는 약간 더 불투명한 **오팔색(Opal White)** 톤의 카드 배경을 사용하여 정보의 가독성을 최우선으로 확보합니다.
3.  **폰트 및 계층:** 제목($H1$)은 산세리프체(예: Inter 또는 Pretendard)의 굵은 폰트로, 지표 값($ARL$, $TRR$ 등)은 수치 자체를 가장 크게 표시하고 단위는 보조적인 크기로 처리하여 **숫자 중심의 사고방식**을 구현합니다.
