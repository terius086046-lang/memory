## 📄 최종 디자인 명세서: Bonus Module 썸네일 및 CTA 컴포넌트

본 문서는 Business가 확정한 **Bonus Module의 핵심 가치(시스템 안정성 ARL)**를 시각적으로 가장 강력하게 전달하고, 최고 전환율을 유도하기 위해 설계된 최종 썸네일 및 CTA 컴포넌트의 디자인 명세입니다. 개발팀이 즉시 프로토타입 제작에 착수할 수 있도록 모든 요소는 구체적인 값과 레이아웃 좌표를 포함합니다.

### 1. 디자인 원칙 요약 (Authority Emphasis & Neumorphism)
*   **핵심 목표:** 시스템 안정성($ARL$)을 시각적으로 강조하여 단순 비용 지불이 아닌 '시스템 접근권 확보'라는 권위를 전달한다.
*   **스타일:** 네오-글래스모피즘 기반의 **Neumorphism** 스타일 유지 (부드러운 그림자, 깊이감).
*   **색상 사용:** Primary Blue (`#1A237E`)와 Accent Teal (`#00BCD4`)을 사용하여 권위(Blue)와 행동 유도(Teal)를 명확히 분리한다.

### 2. 썸네일 컴포넌트 상세 명세 (Thumbnail Component Specification)
**목표:** 시각적 임팩트를 극대화하여 클릭을 유도하고, 시스템 안정성($ARL$)이 핵심 이점임을 즉시 인지시킨다.

| 속성 | 값/설명 | 세부 사양 |
| :--- | :--- | :--- |
| **크기 (Aspect Ratio)** | 16:9 또는 4:5 (인스타그램 최적화) | `1080px` (W) x `1350px` (H) 권장 |
| **배경 색상** | Primary Blue (`#1A237E`) | 깊이감과 권위 강조 |
| **주요 요소** | 중앙 집중형, 텍스트 및 시각적 KPI 배치 | 정보 과부하 방지, 핵심 메시지 집중 |
| **핵심 카피 (Headline)** | "시스템 안정성 ($ARL$)을 확보하라" | Bold, 크기 최대화. Primary Blue 사용. |
| **보조 카피 (Sub-text)** | "Bonus Module: 권위 기반 시스템 접근권" | 중형 폰트, Accent Teal 강조. |
| **시각적 ARL 강조** | **ARL 시각화 바 (Visual Bar)** | 화면 하단에 Primary Blue 배경 위에 Accent Teal 색상의 진행 막대(Progress Bar)를 배치. 현재 $ARL$ 수치를 숫자 형태로 명확히 표시. |
| **네오-글래스모피즘 효과** | 깊은 그림자 처리 | 썸네일 전체에 은은한 소프트 그림자를 적용하여 입체감 부여. |

### 3. CTA 컴포넌트 상세 명세 (Call-to-Action Component Specification)
**목표:** 최종 전환 지점에서 '시스템 접근권' 확보 행위를 가장 매력적이고 권위 있게 제시한다.

| 속성 | 값/설명 | 세부 사양 |
| :--- | :--- | :--- |
| **버튼 유형** | Primary CTA (최우선 행동 유도) | 시스템 안정성($ARL$) 확보 버튼에 집중 |
| **색상 구성** | 배경: Accent Teal (`#00BCD4`) / 텍스트: Primary Blue (`#1A237E`) | 대비를 통한 주목도 극대화. |
| **버튼 형태** | 네오모피즘 스타일의 '부드러운 융기' 효과 | 버튼 영역에 미세한 그림자(Ambient Occlusion)를 적용하여 클릭 가능한 깊이를 표현. |
| **CTA 문구 (Primary)** | "시스템 권한 활성화 ($197)" | 금액($197)과 시스템 접근권이라는 가치를 동시에 제시. |
| **보조 CTA (Secondary)** | "Bonus Module 상세 확인" | 일반 정보 탐색을 위한 보조 옵션. Primary Blue 테두리만 적용. |
| **위치 및 레이아웃** | 썸네일 하단 또는 대시보드 우측 상단 배치 | 시각적 위계를 따라 가장 중요한 액션을 강조. |

### 4. 개발팀 전달 요약 (Developer Handover Summary)

1.  **디자인 시스템:** Neumorphism, Primary Blue (`#1A237E`), Accent Teal (`#00BCD4`) 엄격 적용.
2.  **핵심 시각 요소:** 모든 디자인은 **ARL 수치**를 중심 축으로 하여 권위 강조(Authority Emphasis)를 수행해야 함.
3.  **썸네일 요구사항:** ARL 진행 바는 Teal 색상으로, $ARL$ 수치는 중앙에 크게 표시하며, 전체 레이아웃은 Primary Blue 기반으로 깊이감을 표현할 것.
4.  **CTA 요구사항:** Primary CTA 버튼은 Teal 배경으로, 텍스트는 Blue로 설정하여 즉각적인 행동을 유도해야 함.
